# Security policy

## Supported release

Only the latest Windows release is supported. Installers and update metadata are published from the public `0xMrw1ck/onlysubs-updates` repository.

## Report a vulnerability

Do not open a public issue for a suspected security vulnerability. Email `jakenftwick@gmail.com` with a short description, affected version, and safe reproduction steps. Do not send passwords, tokens, private footage, or data belonging to another person. WickWorks will acknowledge reports when possible; this free beta has no bug bounty or guaranteed response time.

## Safe downloads

Download only from the onlysubs website or the `onlysubs-updates` GitHub releases page. Compare the published SHA-256 checksum. The beta installer is not code-signed yet; do not disable Windows Security to run it.

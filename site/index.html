Before you download

  • This beta installer is unsigned. Keep Windows Security enabled and install only from the official release link.
  • FFmpeg, FFprobe, Python runtime, and faster-whisper are included. Ollama is optional.
  • Your selected speech model downloads on first transcription and may use time and disk space.
  • AI captions need review. Captioned exports are re-encoded, not lossless.
  • The beta has not received an independent security audit or full clean-PC test.

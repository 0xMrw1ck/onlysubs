Before you download

  • Unsigned preview. Keep Windows security enabled; only run software you trust.
  • FFmpeg, FFprobe, Python runtime, and faster-whisper are included. Ollama remains optional.
  • The selected speech model downloads automatically on first transcription and can take time and disk space.
  • Not yet independently audited or verified on a clean Windows PC.
  • AI subtitles need review. Exports with captions are re-encoded, not lossless.
